# Business Logic Model: U12-A テキスト入力パネル

## スコープ

U12-Aは草案テキストをアプリに渡す入力ゲートウェイを実装する。シーン分割・素材推薦・JSON生成はU12-A のスコープ外（U12-B以降）。

## コアワークフロー

### ワークフロー1: テキスト貼り付け → シーン分割開始

1. ユーザーがStudioの「テキスト入力」タブを開く（Workspace未選択でも表示）。
2. ユーザーが草案テキストをテキストエリアに貼り付ける。
3. Workspace選択済みの場合、テキストを `draft-{id}.json` にリアルタイム保存する。
4. ユーザーが「シーンに分割する」ボタンをクリックする。
5. バリデーション：テキストエリアが空の場合エラーを表示し処理を止める。
6. Workspace未選択の場合、Workspace選択を促すメッセージを表示し処理を止める。
7. バリデーション通過後、処理中インジケーターを表示する。
8. U12-B（AIシーン分割エンジン）に処理を委譲する。
9. 分割完了後、シーン調整タブへ自動切り替えする。

### ワークフロー2: ファイル読み込み

1. ユーザーが「ファイルから読み込む」ボタンをクリックする。
2. Electronのファイル選択ダイアログを開く（フィルタ: `.txt`, `.md`）。
3. ユーザーがファイルを選択する。
4. ファイル拡張子が `.txt` / `.md` 以外の場合：エラーダイアログを表示して処理を止める。
5. テキストエリアにすでに内容がある場合：確認ダイアログを表示する。
   - 承認：選択ファイルの内容でテキストエリアを上書きする。
   - キャンセル：上書きしない。
6. テキストエリアが空の場合：確認なしで読み込む。
7. 読み込んだテキストをテキストエリアに反映する。
8. Workspace選択済みの場合、テキストを `draft-{id}.json` に保存する。

### ワークフロー3: アプリ再起動後の復元

1. Workspace選択時に `draft-{id}.json` が存在する場合、ドラフトのテキストフィールドを読み込む。
2. テキスト入力タブを開くと、前回保存したテキストがテキストエリアに表示される。

## ステートモデル

### TextInputState

- `idle`: テキストエリアが空または入力中（シーン分割未実行）
- `has-text`: テキストエリアに内容あり（シーン分割可能）
- `segmenting`: シーン分割処理中（インジケーター表示中）
- `segmentation-error`: シーン分割が失敗した状態

### バリデーション結果

- `ok`: テキストあり・Workspace選択済み → シーン分割可能
- `empty-text`: テキストなし → エラーメッセージ表示
- `no-workspace`: Workspace未選択 → Workspace選択促進メッセージ表示
