# NFR Design Patterns: U12-A テキスト入力パネル

## デバウンスパターン（Debounce Pattern）

- ドラフト保存は500msデバウンスで非同期実行する。
- `useEffect` と `setTimeout` / `clearTimeout` でカスタムフックとして実装する（外部ライブラリ不要）。
- テキスト変更のたびにタイマーをリセットし、500ms無入力が続いた場合のみ保存を起動する。
- デバウンスタイマーはコンポーネントのアンマウント時にもクリアする。

## Fail-Open 保存パターン（Fail-Open Save Pattern）

- ドラフト保存の失敗（ファイルシステムエラー等）はコンソールログへの記録のみを行う。
- 保存失敗によってメモリ上のテキスト状態を変更してはならない。
- 保存失敗をユーザーへ通知しない（UIをブロックしない）。
- 次の500msデバウンス後に自動的に再試行する。メモリが正として機能する。

## Fail-Closed 入力検証パターン（Fail-Closed Validation Pattern）

- ファイルサイズが1MBを超える場合は早期リジェクトし、テキストエリアを変更しない。
- 拡張子が `.txt` / `.md` 以外の場合は早期リジェクトし、テキストエリアを変更しない。
- バリデーションは読み込み処理の前段に配置する（ファイル内容を読む前に弾く）。
- エラー理由はエラーダイアログで明示する（サイズ超過 / 拡張子不正を区別して表示）。

## IPC 境界パターン（IPC Boundary Pattern）

- Electronのファイル選択ダイアログ（`dialog.showOpenDialog`）はMain processのIPCハンドラ経由のみで呼び出す。
- ファイル読み込み（`fs.readFile`）もMain processのIPCハンドラ経由のみで行う。
- Renderer processは直接 `fs` / `path` へアクセスしない。
- 既存のU1・U6 IPCチャンネルと同様のパターンに従う。

## エラー分離パターン（Error Isolation Pattern）

- ファイル読み込みエラーはテキストエリアの既存内容を変更せず、エラーダイアログのみを表示する。
- ドラフト復元失敗（`draft-{id}.json` 読み込みエラー）はコンソールログのみ。テキストエリアは空の状態で開く。
- バリデーションエラー（空テキスト・Workspace未選択）はダイアログではなくインラインメッセージで案内する。
- いずれのエラーもアプリクラッシュを起こしてはならない。

## ロジック抽出パターン（Logic Extraction Pattern）

- バリデーションロジック・ファイル拡張子チェック・ファイルサイズチェックは純粋関数として抽出する。
- 純粋関数はReactコンポーネントもElectronも不要なため、Vitestで直接テストできる。
- ドラフト保存ロジックはサービス関数として分離し、依存注入（`workspaceRoot` 引数）でテスト可能にする。
