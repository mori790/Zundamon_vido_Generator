# NFR Requirements: U12-A テキスト入力パネル

## スコープ

U12-Aはテキストエリアへの貼り付け・ファイル読み込み（.txt/.md）・バリデーション・ドラフト永続化・シーン分割委譲・タブ表示制御を対象とする。シーン分割処理・素材推薦・JSON生成はスコープ外。

## パフォーマンス

- テキストエリアへの入力・貼り付けはReact状態管理の標準挙動で即時反映する（ブラウザ標準動作）。
- ドラフト保存（`draft-{id}.json` 書き込み）は500msデバウンスで非同期実行する。保存処理がUIをブロックしてはならない。
- ファイル読み込み（.txt/.md）は1MB以下のファイルを同期的に読み込む。1MB超のファイルは「ファイルが大きすぎます（1MB以下にしてください）」のエラーダイアログを表示して処理を止める。

## 応答性

- 「シーンに分割する」ボタンのクリック後、処理中インジケーターは即時表示する（1フレーム以内）。
- シーン分割処理中はテキストエリア・FileLoadButton・SegmentationButtonを無効化し、UIがフリーズしているように見せない。
- ドラフト保存の成否にかかわらず、テキストエリアの編集操作はブロックしない。

## 信頼性

- ドラフト保存失敗（ファイルシステムエラー等）は、コンソールログへの記録のみを行う。メモリ上のテキストは保持し、次回の500msデバウンス後に再試行する。ユーザーへの通知は行わない。
- ファイル読み込みエラー（読み取り権限なし等）はエラーダイアログで表示し、テキストエリアの既存内容は変更しない。
- Workspace未選択時のシーン分割試行はエラーダイアログではなくインラインメッセージで案内し、アプリをクラッシュさせない。
- ドラフト復元失敗（`draft-{id}.json` の読み込みエラー）はコンソールログのみ。テキストエリアは空の状態で開く。

## セキュリティ

- ファイル読み込みはElectron dialogを通じたユーザー明示操作に限定する。パスを外部から注入させない。
- `draft-{id}.json` への書き込みはWorkspaceフォルダ内に限定し、Workspace外のパスへは書き込まない。
- テキストエリアの内容はU12-B（Codex）へ渡す前にサイズ上限チェックを行う（U12-Bのスコープ）。

## テスト要件

- **必須（単体テスト）**:
  - `TextInputValidationResult` のロジック（空テキスト・Workspace未選択の各ケース）。
  - DraftPersistenceServiceの `draftText` 読み書きロジック（成功・失敗・再試行）。
  - ファイルサイズ上限チェックロジック（1MB境界値）。
  - ファイル拡張子チェックロジック（.txt/.md 許可、その他拒否）。
- **任意（Reactコンポーネントテスト）**: SegmentationButtonの有効/無効状態切り替えはコンポーネントテストとして追加可能だが今回の必須スコープ外。
- **既存テストへの影響**: U12-Aはタブ追加であり、既存のU1〜U11テストを破壊しない。
