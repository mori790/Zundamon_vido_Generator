# U12 ユーザーストーリー

## フェーズ1: テキスト入力

### US-1: テキストエリアへの草案貼り付け

**優先度**: Must  
**要件対応**: FR-U12-1  
**ペルソナ**: P1

As a 動画制作者,  
I want to 外部で作成した草案テキストをGUIのテキストエリアに貼り付けて入力できる,  
So that 別ファイルを作らずに草案をそのままアプリに渡せる。

**受入条件**

*正常系*
- Given: アプリが起動しており、テキスト入力エリアが表示されている
- When: 任意の形式（自然文・段落区切り・Markdown混在）のテキストをペーストする
- Then: テキストエリアに全文が表示され、入力完了ボタンが有効になる

*失敗系（空入力）*
- Given: テキストエリアが空欄のまま
- When: シーン分割を開始しようとする
- Then: 「テキストを入力してください」というエラーが表示され、処理は始まらない

---

### US-2: テキストファイルの読み込み

**優先度**: Must  
**要件対応**: FR-U12-1  
**ペルソナ**: P1

As a 動画制作者,  
I want to .txt または .md ファイルをアプリに読み込んで草案テキストとして使える,  
So that テキストエディタで保存した草案ファイルをそのまま使える。

**受入条件**

*正常系*
- Given: ファイル読み込みボタンをクリックする
- When: .txt または .md ファイルを選択する
- Then: ファイルの内容がテキストエリアに展開され、以後の操作に使える

*失敗系（非対応形式）*
- Given: ファイル選択ダイアログが開いている
- When: .txt / .md 以外のファイル（.pdf 等）を選択する
- Then: 「.txt または .md ファイルを選択してください」というエラーを表示し、テキストエリアは変更しない

---

## フェーズ2: AIシーン分割

### US-3: AIによる意味的シーン自動分割

**優先度**: Must  
**要件対応**: FR-U12-2  
**ペルソナ**: P1

As a 動画制作者,  
I want to 入力したテキストをAIが意味的なまとまりでシーンに自動分割してくれる,  
So that JSON手作成なしに動画構造の骨格を作れる。

**受入条件**

*正常系*
- Given: テキストエリアに草案テキストが入力されている
- When: 「シーンに分割」を実行する
- Then: AIが意味的境界を検出し、シーンタイトル・ナレーションテキスト・推薦素材タグを含むシーン一覧が表示される
- And: 分割中は処理中インジケーターが表示される
- And: 30シーン以上の結果もすべて一覧に表示される

*失敗系（AI接続エラー）*
- Given: Codex接続が利用できない状態でシーン分割を実行する
- When: AI処理がタイムアウトまたはエラーになる
- Then: 「シーン分割に失敗しました。接続を確認してください」と表示し、テキストエリアの内容は保持する

---

## フェーズ3: シーン調整

### US-4: シーン境界の調整

**優先度**: Must  
**要件対応**: FR-U12-3  
**ペルソナ**: P1

As a 動画制作者,  
I want to AIが提案したシーン境界をドラッグや操作で調整できる,  
So that AIの提案が意図と合わない箇所を自分で修正できる。

**受入条件**

*正常系（並び替え）*
- Given: シーン一覧が表示されている
- When: シーンを上下に並び替える
- Then: シーン順が即時に反映され、変更は自動保存される

*正常系（シーン追加）*
- Given: シーン一覧が表示されている
- When: シーン間に「追加」操作を行う
- Then: 空のシーンが挿入され、ナレーションテキストを入力できる

*正常系（シーン削除）*
- Given: シーン一覧が表示されている
- When: シーンを削除する
- Then: 確認ダイアログの後、シーンが削除される

---

### US-5: シーンナレーションテキストの編集

**優先度**: Must  
**要件対応**: FR-U12-3  
**ペルソナ**: P1

As a 動画制作者,  
I want to 各シーンのナレーションテキストをシーンカードで直接編集できる,  
So that AIの分割結果を細かく調整して完成度を上げられる。

**受入条件**

*正常系*
- Given: シーン一覧のシーンカードが表示されている
- When: シーンのナレーションテキスト欄をクリックして編集する
- Then: 変更は即時反映され、内部JSONへの反映は素材割り当て確定時に行われる

---

## フェーズ4: 素材割り当て・確認編集

### US-6: AIによる素材推薦と承認

**優先度**: Must  
**要件対応**: FR-U12-4  
**ペルソナ**: P1

As a 動画制作者,  
I want to 各シーンにAIが素材（立ち絵・背景・BGM/SE・字幕スタイル・説明画像）を推薦し、一覧で確認・承認できる,  
So that 素材選びの手間を大幅に削減できる。

**受入条件**

*正常系*
- Given: シーン調整が完了しシーン一覧が確定している
- When: 「素材を推薦する」を実行する
- Then: 全シーンに対して立ち絵・背景・BGM/SE・字幕スタイル・説明画像の推薦がシーンカードに表示される
- And: 「承認」ボタンで全推薦を確定できる
- And: 推薦中は非同期インジケーターが表示される

*失敗系（assetsフォルダに素材なし）*
- Given: 対象素材タイプのassetsフォルダが空の場合
- When: 素材推薦を実行する
- Then: 該当タイプに「素材が見つかりません」と表示し、他タイプの推薦は続行する

---

### US-7: 素材の手動変更

**優先度**: Must  
**要件対応**: FR-U12-4  
**ペルソナ**: P1

As a 動画制作者,  
I want to AIの推薦素材をシーンカードのドロップダウンで別の素材に変更できる,  
So that AI推薦が意図と違う場合に自分で選択できる。

**受入条件**

*正常系*
- Given: 素材推薦が表示されているシーンカードがある
- When: 素材タイプのドロップダウンから別の素材を選択する
- Then: 即時に選択した素材に変更され、承認状態が「変更済み」に更新される

---

### US-8: 内部JSONの自動生成と手動修正

**優先度**: Must  
**要件対応**: FR-U12-5  
**ペルソナ**: P1

As a 動画制作者,  
I want to シーン・素材が確定したら内部JSONが自動生成され、必要に応じて手動で修正できる,  
So that JSON手作成は不要だが、細かい調整は引き続きできる。

**受入条件**

*正常系（自動生成）*
- Given: 全シーンの素材割り当てが承認されている
- When: 「JSONを生成する」を実行する
- Then: 既存の `VideoScript` JSON形式で `input/{id}.json` が生成される
- And: 生成されたJSONは台本ドラフト編集UI（既存）で閲覧・編集できる

*正常系（手動修正）*
- Given: 生成されたJSONが台本ドラフト編集UIに表示されている
- When: JSONを直接編集して保存する
- Then: 変更は `input/{id}.json` に書き込まれる
- And: シーン一覧表示と素材割り当て表示は可能な範囲で同期する

---

## フェーズ5: 生成出力

### US-9: VOICEVOX音声生成

**優先度**: Must  
**要件対応**: FR-U12-6  
**ペルソナ**: P1

As a 動画制作者,  
I want to 確定したシーンのナレーションテキストをVOICEVOXに渡して音声ファイルを生成できる,  
So that 手動でナレーション文を作り直さずに音声が生成できる。

**受入条件**

*正常系*
- Given: `input/{id}.json` が生成済みで VOICEVOX Engine が起動している
- When: 音声生成コマンドを実行する
- Then: 全シーンのWAVファイルが生成・キャッシュされる

*失敗系（VOICEVOX未起動）*
- Given: VOICEVOX Engine が起動していない状態で音声生成を実行する
- Then: 「VOICEVOXに接続できません」とエラーを表示し、処理を中断する（fail-fast）

---

### US-10: Remotionプレビュー

**優先度**: Should  
**要件対応**: FR-U12-7  
**ペルソナ**: P1

As a 動画制作者,  
I want to 素材・音声が確定したシーンをRemotionでプレビューできる,  
So that レンダリング前に映像の確認ができる。

**受入条件**

*正常系*
- Given: JSONと音声ファイルが生成済みである
- When: プレビューを起動する
- Then: 既存のRemotionプレビューUI（U7）でシーン映像を確認できる

---

### US-11: MP4レンダリング

**優先度**: Must  
**要件対応**: FR-U12-7  
**ペルソナ**: P1

As a 動画制作者,  
I want to 確認済みのシーン構成からMP4をレンダリングできる,  
So that 完成動画ファイルを出力して配布・確認できる。

**受入条件**

*正常系*
- Given: JSON・音声ファイルが揃っている
- When: レンダリングを実行する
- Then: `output/{id}.mp4` が生成され、0バイトではないことが確認できる

*失敗系（素材ファイル欠損）*
- Given: シーンで参照している素材ファイルが存在しない
- When: レンダリングを実行する
- Then: 欠損素材のパスと対象シーンを示すエラーを表示し、レンダリングを中断する
