# U12 ペルソナ

## P1: 草案テキストを持つ動画制作者

- **役割**: ずんだもん動画の内容を外部（テキストエディタ、AI、メモアプリ等）で文章として作成し、このアプリを使って効率よく動画に組み立てる制作者
- **利用環境**: Apple Silicon Mac、Electron GUI、VOICEVOX Engine（任意）、assetsフォルダに素材を用意済み
- **目標**:
  - 手作業でのJSON作成なしに、草案テキストから動画スクリプトを組み立てる
  - AIが提案したシーン分割と素材推薦を確認・調整して、制作の手間を減らす
  - 既存のVOICEVOX音声生成・RemotionレンダリングパイプラインでMP4を出力する
  - 細かい調整が必要な箇所だけ手動で修正できる
- **制約**:
  - 草案テキストの形式は固定しない（自然文・Markdown・段落区切りなど混在可）
  - 動画1本あたり30シーン以上になることがある
  - assetsフォルダの構造は変えない
  - 新たなライブラリ管理UIは使わない（現行assetsフォルダで管理）
- **成功条件**:
  - 草案テキストを貼り付けるか読み込むだけでシーン分割が始まる
  - 素材推薦を確認して承認・変更すれば、内部JSONが自動生成される
  - VOICEVOXとRemotionで音声・映像が生成され、MP4として出力できる
