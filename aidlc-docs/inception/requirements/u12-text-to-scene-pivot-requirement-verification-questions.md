# U12 方針転換要件確認

## 背景

現行: ユーザーがJSONスクリプト（scene配列）を手作成 → VOICEVOX音声生成 → Remotionレンダリング  
新方針: 外部で作成した動画内容の「草案テキスト」を入力 → アプリがsceneに自動分割 → sceneごとに素材を割り当てる半自動編集フロー

すべての `[Answer]:` へ回答してください。選択肢がある場合は記号を記入し、自由記述の場合はそのまま記載してください。
