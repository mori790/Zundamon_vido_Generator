# Requirements: U12 テキスト起点シーン編集パイプライン（方針転換）

## 要求分析

- **ユーザーリクエスト**: 動画内容の草案テキストを外部で作成し、このアプリでシーンに自動分割して、シーンごとに素材を割り当てる半自動編集フローへ方針転換する。
- **リクエスト種別**: 既存GUIアプリの入力フロー・編集パイプラインの根本的な刷新。
- **スコープ**: テキスト入力 → AIシーン分割 → シーン調整 → 素材割り当て → VOICEVOX → Remotion MP4。既存U1〜U11の全機能を継続使用。
- **複雑度**: 高。AI推論（Codex経由）、GUIシーン編集UI、素材推薦ロジック、既存JSONパイプラインとの接続が絡む。
- **実施方針**: 要件・仕様を固め、実装計画まで作成する（実装は次フェーズ）。

---

## 現行システムとの関係

既存パイプライン（U1〜U11で実装済み）はすべて継続する:

- Electron GUIシェル（U1）
- Codexパネル（U2） ← シーン分割・素材推薦のAIエンジンとして活用
- 台本ドラフト編集UI（U3） ← シーン調整UIとして拡張
- Codex提案フロー（U4）
- デスクトップパッケージング（U5/U10）
- コマンド実行パネル（U6）
- Remotionプレビュー（U7）
- レンダリング・CLIパイプライン（U8〜）

**変更点**: 「ユーザーが`input/{id}.json`を手作成してアプリに渡す」フローを廃止し、「草案テキスト → AIシーン分割 → 内部JSONを自動生成」フローを主流とする。内部JSONは引き続きシーン構造の中間形式として存在し、手動編集も可能。

---

## 新しいデータフロー

```
[外部で作成した草案テキスト]
        ↓ ペースト または ファイル読み込み
[テキスト入力パネル（GUI）]
        ↓ AIシーン分割（Codexへ送信）
[シーン分割提案（30+シーン対応）]
        ↓ ユーザーが境界・テキストを調整
[シーン調整UI]
        ↓ 全素材タイプでAI推薦
[素材推薦パネル → ユーザー承認・変更]
        ↓ 内部JSONスクリプトを自動生成
[VideoScript JSON（手動修正可能）]
        ↓
[VOICEVOX音声生成]  →  [Remotionプレビュー]
        ↓
[MP4レンダリング]
```

## 機能要件

### FR-U12-1: テキスト入力

アプリはユーザーが外部で作成した草案テキストを受け取れること。

- GUIのテキストエリアへの貼り付けに対応する。
- `.txt` / `.md` ファイルの読み込みに対応する。
- テキストの形式は固定しない。自然文をアプリ側で解釈する。
- テキストの文字数・長さに上限は設けないが、UI上で適切にスクロールできること。

### FR-U12-2: AIシーン分割

アプリはCodexパネル（AI）を通じてテキストをシーンに自動分割できること。

- 分割はルールベース（段落）ではなく、意味的まとまり（話題転換、場面切り替え）を基準とする。
- 30シーン以上の大規模分割に対応する。
- 分割提案はシーンタイトル・ナレーションテキスト・推奨素材タグを含む。
- 分割結果はユーザーが確認するまで確定しない。

### FR-U12-3: シーン調整UI

ユーザーはAIが提案したシーン分割を編集できること。

- シーン境界の移動（テキストの再割り当て）。
- シーン順の並び替え。
- シーンの追加・削除。
- 各シーンのナレーションテキストの直接編集。
- 調整後のシーン一覧はリアルタイムで表示される。

### FR-U12-4: 素材割り当て（AI推薦 + 人間確認）

各シーンに対してアプリが素材を推薦し、ユーザーが承認または変更できること。

対象素材タイプ:
- **立ち絵**: ずんだもんのキャラクター画像（表情・ポーズ）
- **背景画像**: シーンの場面に合った背景
- **BGM / SE**: 音楽・効果音
- **テキストオーバーレイ・字幕スタイル**: フォント、色、位置
- **説明画像**: illustration（図解・資料画像）

推薦ロジック:
- シーンのナレーションテキストと推薦タグをCodexへ渡し、assetsフォルダの候補リストから推薦する。
- 推薦は確認ダイアログまたはシーンカードのサイドパネルで提示する。
- ユーザーは推薦を承認するか、ドロップダウン等で別素材に変更できる。
- 素材ライブラリは現行の `assets/` フォルダ構造をそのまま使用する。新しいライブラリ管理UIは今回スコープ外。

### FR-U12-5: 内部JSONの自動生成と手動修正

シーン調整・素材割り当てが完了したとき、アプリは既存の `VideoScript` JSON形式（`input/{id}.json`）を自動生成すること。

- JSON手作成は不要（廃止）。
- 生成されたJSONはユーザーが直接閲覧・手動修正できる（既存の台本ドラフト編集UIを活用）。
- 手動修正後はシーン一覧・素材割り当て表示と同期する。

### FR-U12-6: VOICEVOX連携

シーン確定後、ナレーションテキストをそのままVOICEVOXへ渡して音声を生成する。

- 現行の音声生成フロー（`generate-voices.ts`）を再利用する。
- シーンテキストとナレーションテキストは同一（草案テキストを編集したもの）。
- スピーカー設定は動画レベルで指定する（現行と同じ）。

### FR-U12-7: プレビューとレンダリング

- 既存のRemotionプレビュー（U7）でシーンを確認できる。
- 既存のレンダリングパイプラインでMP4を出力する。
- 出力形式は現行と同じMP4。

## 非機能要件

### NFR-U12-1: スケール
- 30シーン以上のシーン分割・表示・編集に対応する。
- UIは100シーン程度まで操作性を損なわずスクロール・表示できる。

### NFR-U12-2: レスポンス
- AIシーン分割はCodex（非同期）のため待機インジケーターを表示する。
- シーン調整UIの操作（並び替え・境界変更）は即時反映する（Codex呼び出しを伴わない）。
- 素材推薦はシーン確定後に非同期で取得する。

### NFR-U12-3: データ保全
- 草案テキストは編集中にローカル保存（ドラフト永続化）する。
- シーン調整の途中状態を保持し、アプリ再起動後に再開できる。

### NFR-U12-4: 後方互換
- 既存の `input/{id}.json` を直接開いて編集する経路は削除しない（レガシー互換）。
- 新テキスト入力フローはオプションの追加エントリポイントとして位置づける（当面）。

---

## スコープ外（今回）

- 素材ライブラリ管理UI（assetsフォルダへの追加・削除・タグ付け）
- 複数プロジェクトの同時編集
- クラウド保存・共有
- シリーズ管理
- テンプレートライブラリ
